# Fighting Game · 精灵对战

一款使用 **Java Swing** 开发的回合制精灵对战游戏，融合了属性克制、技能学习与肉鸽式闯关玩法。

---

## 项目简介

玩家注册并选择属性（火 / 草 / 水）后开始闯关。每一关会遭遇一只随机属性的精灵，通过策略性地使用技能击败对手。每通过若干关卡可进入「属性分配 + 技能学习」奖励界面，不断强化自己，直到被击败为止。

- **纯 Java 实现**，仅依赖 JDK 自带的 Swing，无需任何第三方库
- **单机运行**，用户数据保存在内存中（关闭程序后重置）

---

## 功能特性

### 属性克制

三种属性形成相互克制关系，克制时伤害变为 **1.5 倍**，被克制时降为 **0.75 倍**。

| 克制关系 | 效果 |
| --- | --- |
| 火 → 草 | 火系攻击草系伤害 ×1.5 |
| 草 → 水 | 草系攻击水系伤害 ×1.5 |
| 水 → 火 | 水系攻击火系伤害 ×1.5 |

> 前两关敌人不会随机出「克制玩家属性」的精灵，避免新手期出现不可避免的翻车。

### 技能系统

玩家初始拥有 **属性技能 + 普通攻击**，可通过奖励界面扩充至最多 **4 个技能槽**。

**可学习技能池**

| 技能 | 效果 | 冷却 |
| --- | --- | --- |
| 强力一击 | 造成 150% 攻击力伤害，自损 8% 最大生命 | 1 回合 |
| 生命吸取 | 造成 70% 伤害并回复等量生命 | 1 回合 |
| 电光一闪 | 造成 60% 伤害并回复 5 点生命 | 无 |
| 铁壁 | 本回合额外获得 30% 减伤 | 2 回合 |
| 治愈之愿 | 回复 25% 最大生命 | 3 回合 |
| 破甲一击 | 造成 120% 伤害，无视敌方半数减伤 | 2 回合 |
| 狂暴 | 造成 200% 攻击力伤害，自损 12% 最大生命 | 3 回合 |
| 聚气 | 永久提升 10% 基础攻击力 | 3 回合 |

**平衡设计原则**：每个技能都必须付出代价（冷却 / 自损 / 低倍率），高收益技能冷却更长。自损类技能不会把自己打死（至少保留 1 点生命，且自损上限为当前生命的 15%）。

### 敌人技能

敌人技能会随关卡逐步解锁，越往后越多样化：

| 技能 | 效果 | 解锁关卡 |
| --- | --- | --- |
| 撕咬 | 100% 攻击力伤害 | 1 |
| 电光一闪 | 70% 攻击力伤害 | 2 |
| 挑衅 | 提升自身 20% 攻击力 | 3 |
| 属性技能 | 110% 属性攻击 | 3 |
| 重击 | 150% 伤害（25% 概率落空） | 4 |
| 休养生息 | 生命低于一半时回复 25% | 5 |
| 吸取之吻 | 60% 伤害并回复等量生命 | 5 |
| 背水一战 | 生命低于 30% 时 180% 伤害，自损 8% | 6 |

### 闯关与奖励

- **奖励关卡**：第 **2、4** 关通关后各奖励一次，之后每 **3** 关奖励一次（7、10、13…）
- **奖励内容**：回复 35% 最大生命 + 5 点自由分配属性 + 学习 1 个新技能
- **非奖励关卡**：通关后回复 12% 最大生命作为整备
- **技能学习**：技能槽满时需先遗忘一个技能（普通攻击不可遗忘）

### 战败与重开

战败后可选择：

- **重新开始** —— 用同一账号新建角色，属性完全重置，从第 1 关重新开始
- **退出游戏** —— 返回主菜单

## 运行方式

### 环境要求

- JDK 17 或更高版本（项目使用 `switch` 表达式等新语法）

### 编译

**必须在项目根目录执行**（背景图使用相对路径加载）：

```powershell
javac -encoding UTF-8 -d out (Get-ChildItem -Recurse src -Filter *.java | ForEach-Object { $_.FullName })
```

### 运行

```powershell
java -cp out app
```

> ⚠️ 若不在项目根目录运行，背景图将无法加载（控制台会提示「背景图片不存在」），但游戏仍可运行。

### 使用 IDE

用 IntelliJ IDEA 打开项目根目录，将 `src` 标记为源码根目录，运行 `app` 类的 `main` 方法即可。

## 难度设计

敌人数值随关卡按次线性函数增长，保证前期平缓、后期递增：

```
生命值 = 70 + 22 × 关卡^0.92
攻击力 = 6 + 2.2 × 关卡^0.85
防御力 = 第 6 关起每关 +2（上限 10）
```

前两关额外打 85 折。经 900 局自动化模拟验证：**第 1~5 关通过率 100%**，平均可到达第 9 关。
